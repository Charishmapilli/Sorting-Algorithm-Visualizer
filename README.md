Sorting Algorithm Visualizer

A web-based Sorting Algorithm Visualizer that demonstrates how different sorting algorithms work through step-by-step visualization.

📌 About the Project

This project helps users understand sorting algorithms by displaying the array changes at every step. Users can enter their own numbers and visualize the sorting process using bars or an array representation.

The project is designed to make sorting algorithms easier to understand through visualization, working steps, pseudocode, and programming code.

🚀 Features

- Enter custom numbers for sorting
- Step-by-step sorting visualization
- Bar View and Array View
- Displays the current array at every step
- Highlights the elements currently being compared or swapped
- Working Steps panel
- Pseudocode for each algorithm
- C++, Python, and Java code
- Previous and Next step controls
- Auto Play feature
- Reset option
- Comparison and swap counts
- Time and space complexity information

🔢 Sorting Algorithms

The visualizer supports:

1. Bubble Sort
2. Insertion Sort
3. Selection Sort
4. Quick Sort
5. Merge Sort

▶️ How to Run

1. Clone the repository

2. Open the project folder

cd SORTING

3. Install Flask

pip install flask

4. Run the application

python app.py

5. Open in browser

http://127.0.0.1:5000
